# 🎬 Movie Finder

A responsive React + TypeScript movie discovery application powered by the TMDB API.

## Features

- Search movies
- Popular movies
- Movie cards
- Movie details
- Movie ratings
- Release dates
- Movie genres
- Genre filtering
- Favorite movies
- LocalStorage persistence
- Responsive design
- Loading states
- Error handling
- React Router navigation
- Reusable components
- TypeScript interfaces
- API integration

## Technologies

- React
- TypeScript
- Vite
- React Router
- TMDB API
- CSS
- LocalStorage
